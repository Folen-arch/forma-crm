# Forma — CRM для фрилансера

Рабочее пространство для независимых специалистов и небольших студий. Forma помогает вести клиентов, проекты, задачи и финансы в одном месте.

## Стек

- Next.js App Router и React
- TypeScript
- PostgreSQL, Drizzle ORM и SQL-миграции
- Zod для проверки входных данных API
- Better Auth: регистрация, вход, сессии и изоляция данных по рабочим пространствам
- Tailwind CSS 4 и собственные стили компонентов

## Что уже работает

- Адаптивная панель студии на русском языке
- Поиск по клиентам и проектам
- Добавление, редактирование и удаление клиентов и проектов через API
- Проверка данных на сервере
- Связь проекта с клиентом, если он уже есть в рабочем пространстве
- PostgreSQL-схема для рабочих пространств, клиентов и проектов
- Раздельные списки клиентов, проектов и проектных бюджетов
- Создание, редактирование, завершение и удаление задач с датой, временем и привязкой к проекту
- Счета с проектом, суммой, сроком оплаты и статусом; финансовые итоги рассчитываются по счетам
- Документы рабочего пространства: загрузка и скачивание PDF, DOCX, XLSX, PNG, JPG и WEBP до 4 МБ с привязкой к клиенту или проекту; файлы хранятся в PostgreSQL
- Лента истории и уведомления о создании, изменении и удалении клиентов, проектов, задач, счетов и документов; непрочитанные события помечаются отдельно

Первый зарегистрированный пользователь получает подготовленное демо-пространство с примерами. Для входа и работы приложения PostgreSQL должен быть запущен.

## Локальный запуск

Нужны Node.js 20.9+ и pnpm.

1. Установите пакеты и создайте локальный файл окружения:

   ```powershell
   pnpm install
   Copy-Item .env.example .env.local
   ```

   Сгенерируйте секрет Better Auth командой `pnpm exec auth secret` и замените значение `BETTER_AUTH_SECRET` в `.env.local`.

2. Запустите PostgreSQL. Если установлен Docker:

   ```powershell
   docker compose up -d postgres
   ```

   Либо укажите в `.env.local` URL другой PostgreSQL базы в переменной `DATABASE_URL`.

3. Примените миграции и добавьте демонстрационные данные (клиентов, проекты, задачи и счета):

   ```powershell
   pnpm db:migrate
   pnpm db:seed
   ```

4. Запустите приложение, откройте его и зарегистрируйте аккаунт:

   ```powershell
   pnpm dev
   ```

Откройте [http://localhost:3000](http://localhost:3000).

## Публикация на Netlify

Проект настроен для сборки в Netlify через Next.js adapter. Перед подключением создайте облачную PostgreSQL-базу и загрузите проект в Git-репозиторий.

1. В Netlify выберите **Add new project → Import an existing project** и подключите Git-репозиторий. Netlify использует `netlify.toml` для команды сборки и версию Node.js.
2. В **Project configuration → Environment variables** добавьте для Production и Deploy Previews:
   - `DATABASE_URL` — строка подключения к облачному PostgreSQL; для serverless рекомендуется pooled URL провайдера.
   - `BETTER_AUTH_SECRET` — отдельный случайный секрет. Создайте его командой `pnpm exec auth secret`; не публикуйте и не добавляйте в Git.
   - `BETTER_AUTH_URL` — постоянный HTTPS-адрес production-сайта, например `https://ваш-проект.netlify.app`.
3. Примените миграции и демоданные к облачной базе до первой регистрации. Из PowerShell, в копии проекта, задайте `DATABASE_URL` на время команд:

   ```powershell
   $env:DATABASE_URL = "строка-подключения-к-облачной-базе"
   pnpm db:migrate
   pnpm db:seed
   Remove-Item Env:DATABASE_URL
   ```

   Вставьте строку подключения только в локальный терминал и не сохраняйте её в репозитории.
4. Запустите первый production deploy и зарегистрируйте аккаунт. Deploy Previews используют production-базу только если вы включили для них ту же переменную `DATABASE_URL`; при необходимости заведите отдельную базу для превью.

Файлы ограничены 4 МБ, чтобы укладываться в ограничение Netlify Functions для бинарных запросов. Бесплатный тариф Netlify имеет месячный лимит использования, поэтому публичная демоверсия может приостанавливаться при его исчерпании.

## Работа со схемой

После изменений в `src/db/schema.ts` сгенерируйте миграцию и примените её:

```powershell
pnpm db:generate
pnpm db:migrate
```

`pnpm db:studio` открывает Drizzle Studio для просмотра содержимого базы.
